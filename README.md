# master-ms-skill

المستودع الرسمي والموحد لأداة كتابة وتدقيق رسائل الماجستير العربية:

**https://github.com/Abbara-HaH/master-ms-skill**

لا تستخدم مستودعاً منفصلاً لإطار تقييم جديد أو نسخاً قديمة من مهارة الأنسنة. الأمر المعتمد لهذا المشروع هو:

```text
/ma-thesis
```

## ما الذي يحتويه المستودع

| المسار | الوظيفة |
|---|---|
| `ma-thesis/SKILL.md` | تعريف المهارة والأوامر والأحكام H1–H16 وسير الكتابة |
| `ma-thesis/references/guide/` | دليل المعهد المصدري G01–G16 بوزن مرجعي مقداره 40% |
| `ma-thesis/references/` | قواعد سير العمل والنصوص والفقرات والفصول والدراسات السابقة والأنسنة |
| `ma-thesis/agents/` | وكلاء التحقق والنقد والنزاهة |
| `ma-thesis/templates/` | قوالب المخطط والفقرة والفصل والتقرير |
| `ma-thesis/scripts/` | جواز المشروع، فحص التنسيق، الأنسنة، والتحقق من دليل المعهد |
| `ma-thesis/claude-code/` | تثبيت المهارة والوكلاء في Claude Code |
| `ma-thesis/tools/` | وحدة تشغيل الوكلاء في claude.ai |
| `CHANGELOG.md` | سجل التحديثات والإصدارات |

## تثبيت المهارة في Claude Code

من داخل مجلد المستودع:

```bash
bash ma-thesis/claude-code/install.sh
```

للتثبيت داخل مشروع واحد فقط:

```bash
bash ma-thesis/claude-code/install.sh --project
```

بعد إعادة تشغيل Claude Code:

```text
/ma-thesis
```

لإزالة التثبيت:

```bash
bash ma-thesis/claude-code/install.sh --uninstall
```

## سير التسليم المعتمد

```text
كتابة
  -> فحص الفقرات والبنية
  -> الأنسنة الإلزامية
  -> style_lint وformat_check
  -> بوابة النزاهة
  -> عرض النسخة الأنسيّة على اللجنة
  -> ردود وتعليقات الباحث فقط
  -> التعديل بعد موافقة الباحث
  -> إعادة الأنسنة والفحص
  -> موافقة الباحث النهائية
  -> تسليم ملف Markdown واحد
```

لا يتم التسليم النهائي بمجرد اكتمال الكتابة. ولا تعتبر الأنسنة مضمونة لاجتياز كاشف ذكاء اصطناعي.

## وزن المصادر

تعطي المهارة الأولوية المرجعية التالية:

1. **دليل المعهد: 40%** للهياكل والصفحات والترقيم والتوثيق والمنهج.
2. **الرسالة الكاملة المقدمة للباحث: 40%** للبيانات والمنهج والنتائج والسياق.
3. **الجزء الجزئي المرفق: 20%** لأمثلة النمط والفقرة والكتابة الكمية فقط، وليس لفرضية أو رقم أو مرجع.

هذه الأوزان لا تمنع اختلاق شيء. الأرقام والمراجع والإجراءات تخضع دائماً لما يوفره الباحث وما يحققه المتحقق.

## المخرجات

- يكتب كل قسم مسودة Markdown في `drafts/`.
- ينهي كل مسودة جدول الالتزام، ويعرض ما لم يمكن التحقق منه.
- يمنع التسليم النهائي وجود فراغات موسومة مفتوحة أو ادعاءات رقمية غير مسجلة.
- يحتاج المخرج إلى موافقة الباحث قبل التسليم النهائي.

## التحقق من التحديثات

نسخة المستودع المرجعية هي:

- الفرع: `main`
- الإصدار المعتمد: انظر `CHANGELOG.md`
- آخر رقم commit: انظر سجلات GitHub في المستودع الصحيح أعلاه

لا يمكن اعتبار `Ma-skills` مستودعًا معتمدًا لسير `/ma-thesis`.
