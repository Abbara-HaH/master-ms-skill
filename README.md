# master-ms-skill

المستودع الرسمي والموحد لأداة كتابة وتدقيق رسائل الماجستير العربية:

**https://github.com/Abbara-HaH/master-ms-skill**

لا تستخدم مستودعاً منفصلاً لإطار تقييم جديد أو نسخاً قديمة من مهارة الأنسنة. الأمر المعتمد لهذا المشروع هو:

```text
/ma-thesis
```

## ما الذي يحتويه المستودع

| المسار | الوظيفة |
|---|---|
| `ma-thesis/SKILL.md` | تعريف المهارة والأوامر والأحكام H1–H18 وسير الكتابة |
| `ma-thesis/commands/` | مداخل أوامر Claude Code للإضافة، ومنها `/ma-thesis:full` |
| `ma-thesis/references/guide/` | دليل المعهد المصدري G01–G16 بوزن مرجعي مقداره 40% |
| `ma-thesis/references/` | قواعد سير العمل والنصوص والفقرات والفصول والدراسات السابقة والأنسنة |
| `ma-thesis/agents/` | وكلاء التحقق والنقد والنزاهة |
| `ma-thesis/templates/` | قوالب المخطط والفقرة والفصل والتقرير |
| `ma-thesis/scripts/` | جواز المشروع، فحص التنسيق، الأنسنة، والتحقق من دليل المعهد |
| `ma-thesis/claude-code/` | تثبيت المهارة والوكلاء في Claude Code |
| `ma-thesis/tools/` | وحدة تشغيل الوكلاء في claude.ai |
| `CHANGELOG.md` | سجل التحديثات والإصدارات |

## تثبيت الإضافة في Claude Code

أضف سوق المستودع ثم ثبّت إضافة `ma-thesis` من واجهة Claude Code:

```text
/plugin marketplace add Abbara-HaH/master-ms-skill
/plugin install ma-thesis@master-ms-skill
```

مدخل الإضافة العام هو `/ma-thesis:ma-thesis`. ولتشغيل مسار كتابة الرسالة كاملة مباشرةً:

```text
/ma-thesis:full <عنوان البحث أو فكرته>
```

هذا الأمر يحمّل مباشرةً `SKILL.md` ومسار التأليف وخرائط الفصول ومعايرة الفقرات، ثم يتبع مراحل S0–S9 وبوابتي G-A وG-B. ويظل `/ma-thesis:ma-thesis full <العنوان>` مساراً مكافئاً. شغّل `python3 ma-thesis/scripts/validate_plugin.py` للتحقق من بقاء مدخلي الإضافة موصولين بهذه التعليمات. الفحص البنيوي لا يغني عن اختبار جلسة Claude Code فعلية.

## تثبيت المهارة المستقلة في Claude Code

من داخل مجلد المستودع:

```bash
bash ma-thesis/claude-code/install.sh
```

للتثبيت داخل مشروع واحد فقط:

```bash
bash ma-thesis/claude-code/install.sh --project
```

بعد إعادة تشغيل Claude Code، يستمر هذا المثبّت المستقل باستخدام:

```text
/ma-thesis
```

لإزالة هذا التثبيت المستقل:

```bash
bash ma-thesis/claude-code/install.sh --uninstall
```

## الأوامر

في التثبيت المستقل استخدم `/ma-thesis`؛ أما الإضافة المثبتة من السوق فتستخدم `/ma-thesis:full` للمسار الكامل أو `/ma-thesis:ma-thesis` للأوضاع الأخرى.

| الأمر | النتيجة |
|---|---|
| `/ma-thesis full <العنوان أو الفكرة>` | كتابة البحث كاملًا فصلًا فصلًا بعد جمع المدخلات، مع حفظ المراحل والاستئناف |
| `/ma-thesis plan <العنوان>` | مخطط بحث مؤلف من العناصر الأربعة عشر |
| `/ma-thesis write <القسم>` | كتابة قسم واحد بعد جمع مدخلاته |
| `/ma-thesis lit` | البحث والتحقق وكتابة الدراسات السابقة |
| `/ma-thesis continue` | الاستئناف من آخر مرحلة محفوظة في الجواز |
| `/ma-thesis fix` | تصحيح لغوي أو منهجي أو توثيقي مع سجل التغييرات |
| `/ma-thesis adapt` | تكييف نص موجود مع بنية دليل المعهد |
| `/ma-thesis humanize [ملف أو نص]` | إعادة الصياغة الأكاديمية الطبيعية مع الحفاظ على المحتوى |
| `/ma-thesis review` | مراجعة صارمة كجلسة لجنة مناقشة |
| `/ma-thesis verify` | التحقق من المراجع والادعاءات |
| `/ma-thesis format` | فحص التنسيق والأرقام والفراغات |
| `/ma-thesis status` | المرحلة والبوابة والفراغات المفتوحة |
| `/ma-thesis save` | حفظ حزمة الجواز |
| `/ma-thesis load` | استئناف الجواز من الحزمة |

### وضع كتابة البحث كاملًا

الأمر `full` يبدأ مسار تأليف متكامل، لا ينتهي بإعداد مخطط أو قسم واحد. تجمع الأداة المعلومات الناقصة منك في أسئلة مركزة، ثم تكتب العنوان والفصول والمراجعة النظرية والمنهج والنتائج والمقدمة والملخصات وفق دليل المعهد. تُحفظ المسودات ويجري العمل فصلًا فصلًا مع موافقاتك. لا تختلق الأداة مراجع أو بيانات أو نتائج؛ إن لم تتوفر بيانات ميدانية، تتوقف عن كتابة النتائج وتوضح ما يلزم لاستكمال المسودة.

يعني «صوت الباحث» التحليل والتركيب والتفسير المبني على معلوماتك، لا اختلاق تجربة شخصية ولا استخدام ضمير المتكلم خلاف دليل المعهد. مشكلة البحث والأقسام المحددة في H13 تبقى بلا مراجع، بينما توثق الأدبيات في مواضعها المناسبة. تُكتب الفقرات بنثر أكاديمي مترابط، لا كعناوين فقط أو ملخصات مصادر متتابعة.

تستخدم الأداة `ma-thesis/references/chapter_architecture_map.md` للفصول الثلاثة الأولى، و`chapter4_5_architecture.md` للفصلين الرابع والخامس ومصفوفة التغطية الكاملة، و`paragraph_sentence_blueprint.md` لتخطيط وظائف الجمل وطول الفقرة. التوازن يعني عدم إسقاط أي قسم، لا فرض عدد صفحات متساوٍ على الفصول.

## سير التسليم المعتمد

```text
كتابة
  -> فحص الفقرات والبنية
  -> الأنسنة الإلزامية
  -> style_lint وformat_check
  -> بوابة النزاهة
  -> عرض النسخة الأنسيّة على اللجنة
  -> ردود وتعليقات الباحث فقط
  -> التعديل بعد موافقة الباحث
  -> إعادة الأنسنة والفحص
  -> موافقة الباحث النهائية
  -> تسليم ملف Markdown واحد
```

لا يتم التسليم النهائي بمجرد اكتمال الكتابة. ولا تعتبر الأنسنة مضمونة لاجتياز كاشف ذكاء اصطناعي.

## وزن المصادر

تعطي المهارة الأولوية المرجعية التالية:

1. **دليل المعهد: 40%** للهياكل والصفحات والترقيم والتوثيق والمنهج.
2. **الرسالة الكاملة المقدمة للباحث: 40%** للبيانات والمنهج والنتائج والسياق.
3. **الجزء الجزئي المرفق: 20%** لأمثلة النمط والفقرة والكتابة الكمية فقط، وليس لفرضية أو رقم أو مرجع.

هذه الأوزان لا تمنع اختلاق شيء. الأرقام والمراجع والإجراءات تخضع دائماً لما يوفره الباحث وما يحققه المتحقق.

## المخرجات

- يكتب كل قسم مسودة Markdown في `drafts/`.
- ينهي كل مسودة جدول الالتزام، ويعرض ما لم يمكن التحقق منه.
- يمنع التسليم النهائي وجود فراغات موسومة مفتوحة أو ادعاءات رقمية غير مسجلة.
- يحتاج المخرج إلى موافقة الباحث قبل التسليم النهائي.
- اختبارات قبول وضع الكتابة الكاملة موثقة في `ma-thesis/FULL_RESEARCH_TESTS.md`؛ لا تُعتبر نتائج هذه الاختبارات مثبتة حتى تنفذ جلسات مستقلة.
