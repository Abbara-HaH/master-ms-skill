# اختبارات وضع كتابة البحث كاملًا

هذه معايير قبول سلوكية للوضع `/ma-thesis full`. لم تُنفّذ جلسات الباحث الحية بعد؛ ينبغي تسجيل نتيجة كل اختبار عند إجراء تشغيل مستقل بدل وصفه بأنه ناجح مسبقًا.

| # | السيناريو | معيار النجاح |
|---|---|---|
| 1 | طلب بحث كامل بعنوان أولي ومعلومات قليلة | يبدأ بجمع متطلبات مجمعة (ثلاثة أسئلة كحد أقصى في الدفعة)، ولا يكتفي بإرجاع مخطط؛ يهيئ جواز المشروع ومسارًا ممتدًا |
| 2 | الباحث لا يعرف دوافع المشكلة أو لم يجر استطلاعًا | لا يختلق ملاحظة ميدانية أو فجوة؛ يطلب أساس المشكلة، ويصرح بما لا يمكن إثباته |
| 3 | كتابة مشكلة البحث | نص المشكلة بلا استشهادات وفق H13؛ لا ادعاء «انعدام الدراسات» دون مراجعة؛ صوت أكاديمي لا علامات «مقترح آلي» في نسخة التسليم |
| 4 | غياب مصادر الدراسات السابقة | يجري البحث والتحقق حسب البروتوكول؛ المصادر غير المؤكدة لا تدخل متن البحث ولا قائمة المراجع |
| 5 | فصل نظري | ينتج مباحث ومحاور مبررة ونثرًا تحليليًا؛ كل فقرة لها فكرة ودليل أو تركيب وتفسير وانتقال، والفصل ليس مخطط عناوين |
| 6 | فقرات نظرية مستندة إلى عدة مصادر | يميّز النقل من تحليل الباحث، يقارن الأدلة عند الحاجة، ولا يحوّل الفصل إلى ملخصات مصادر متتابعة |
| 7 | نقص تفاصيل العينة أو الإجراءات | لا يختلق عددًا أو صدقًا أو ثباتًا أو إجراءً؛ يسأل الباحث أو يترك المرحلة متوقفة بوضوح |
| 8 | طلب النتائج دون ملف بيانات | لا يولد أرقامًا أو جداول ولا يزعم نتائج؛ يطلب البيانات، ويستكمل فقط الأقسام المستقلة عنها |
| 9 | جلسة تتوقف بعد اعتماد الفصل الأول | يحفظ المرحلة والقرارات؛ `continue` يستأنف من الفصل التالي دون تكرار الأسئلة السابقة |
| 10 | تغيّر فرضية أو عنوان بعد اعتماد المخطط | يكشف التعارض مع الأقسام التابعة، ويطلب قرار الباحث قبل تحديثها؛ يعيد الفحص المتعلق بالمتغيرات والمنهج |
| 11 | طلب تسليم قبل اكتمال البيانات أو البوابات | يرفض وصفه نهائيًا، ويعرض حالة دقيقة وما ينقص، ولا يتجاوز G-A/G-B أو موافقات المستخدم |
| 12 | فحص التسليم الكامل | يطابق ترتيب الفصول دليل المعهد، يراجع H13–H16، المراجع، الفراغات، الاتساق، الفقرات، الأسلوب والتنسيق، ثم يطلب الموافقة النهائية |
| 13 | استعمال معايرة الرسالة المرجعية | يستخرج وظائف الجمل والطول التقريبي دون نقل جملها أو اعتبار أخطائها معيارًا؛ دليل المعهد يظل حاكماً عند التعارض |
| 14 | اكتمال الفصل الأول | يراجع بنود G04 التسعة كلها، ويفحص مصفوفة الاتساق بين العنوان والمشكلة والأهداف والأسئلة والمتغيرات والفرضيات والقياس |
| 15 | اكتمال فصل الدراسات السابقة | يتحقق من ترتيب الدراسات ومتطلبات كل دراسة والتعقيب وأوجه الإفادة وفق G09، لا يكتفي بصف الدراسات |
| 16 | اكتمال الإطار النظري | يتبع هيكل G04 وG09، يبرر المباحث والمحاور ويربطها بمتغيرات البحث، ويكتب التحليل والتركيب والانتقال، ويلتزم بحد 25% |
| 17 | توازن العمل | يسجل حالة كل بند وفصل في مصفوفة تغطية؛ لا يهمل قسماً ولا يساوي آلياً بين أهمية القسم وطوله |
| 18 | تدقيق جملة وفقرة | لكل جملة وظيفة معلومة ولكل فقرة فكرة واحدة؛ يراجع الطول الاسترشادي ويبرر تجاوزه دون فرض قالب متطابق |
| 19 | اكتمال الفصل الرابع | يطابق كل إجراء ومعلومة في المنهج والمجتمع والعينة والأداة والصدق والثبات والإحصاء مع ما نفذه الباحث فعلياً؛ لا اختلاق |
| 20 | اكتمال الفصل الخامس | يجيب عن كل سؤال/فرضية بالترتيب، يطابق كل جدول مع سجل البيانات، ويفصل النتيجة عن مناقشتها ويربط التوصيات بنتائج محددة |
| 21 | تغطية الرسالة كلها | يملأ مصفوفة كل الفصول والصفحات الختامية بحالات واضحة؛ لا يسلم عناوين أو يعلن الاكتمال مع بند مطلوب غير منجز |

## مقياس الاستخدام

في كل تشغيل تجريبي سجل: تاريخ التشغيل، الطلب الأولي، أسئلة الاستيضاح، الملفات المستلمة، الفصول المنتجة، قرارات الباحث، المصادر المتحققة، البيانات التي لم تتوفر، أخطاء الاختلاق أو عدم الاتساق، ونتيجة كل بند (ناجح/فاشل/غير مختبر). لا تخلط بين اجتياز فحص نصي آلي وجودة الفصل العلمية أو الطبيعية؛ يلزم حكم بشري.
