# بطاقة بناء فقرة أكاديمية

- الفصل / المبحث / العنوان الفرعي:
- نوع الفقرة ووظيفتها:
- الفكرة المركزية الواحدة:
- تسلسل الجمل ووظيفة كل جملة (TOPIC / CONTEXT / EVIDENCE / LINK / ANALYSIS / SYNTHESIS / LOCAL / BRIDGE):
- طول تقريبي مستهدف (مرن؛ كلمة/عدد جمل):
- الدليل المتحقق أو بيانات الباحث، وما الدعوى التي يسندها:
- ما هو نقل مصدر وما هو تحليل/تركيب الباحث:
- النتيجة المحلية:
- الجسر المنطقي للفقرة التالية:

## فحص القبول

- لكل جملة وظيفة، ولا تكرر وظيفة جملة سابقة بلا إضافة.
- فكرة مركزية واحدة وتسلسل مفهوم.
- الدليل يدعم الدعوى المحددة ولا يتجاوزها.
- تحليل/تركيب الباحث ظاهر حيث يحتاج السياق، من دون نسبة رأي مختلق إليه.
- لا تتحول الفقرة إلى سلسلة ملخصات مراجع.
- تنتهي بنتيجة محلية أو انتقال مبرر، لا بحشو ختامي.
- الطول قريب من المعايرة المرنة في `references/paragraph_sentence_blueprint.md`، أو له مبرر واضح.
- الاستشهاد مطابق لقواعد هذا القسم ودليل المعهد.
